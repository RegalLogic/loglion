# MSI Log

MSI Log files record the detailed activity of the Windows Installer (MSI) engine as it processes an installation, repair, or removal operation. They are generated by running an installer with verbose logging enabled, for example:

```
msiexec /i setup.msi /l*v install.log
```

MSI logs capture every action, condition evaluation, registry write, file copy, and error message produced during setup. They are the primary tool for diagnosing failed or misbehaving Windows Installer packages.

## Tips

- Filter for `Return value 3` to immediately locate installation failures.
- Filter for `Error` or `SFXCA` to find custom action issues.
- The **Context** column shows which MSI action (e.g., *InstallFiles*, *WriteRegistryValues*) was executing when each message was produced — useful for narrowing down the problem area.
- The **ID** column shows the process and thread ID, which helps correlate entries when multiple MSI processes run concurrently.
- Log Lion auto-detects MSI log files by their characteristic header format.

## Columns

| Column | Description |
| --- | --- |
| **Message** | The installer message or diagnostic text produced by the MSI engine or a custom action. |
| **Time** | Timestamp when the message was written. |
| **Context** | The MSI action or component context that produced the message (e.g., *InstallFiles*, *CostFinalize*). |
| **ID** | Process and thread identifier in the form *Process:Thread*. |

## Entry Types

| Type | Description |
| --- | --- |
| **Clients** | Messages from the MSI client process (the installer UI or command-line msiexec calling the engine). |
| **Servers** | Messages from the MSI server process (the elevated engine that performs privileged operations). |
| **Others** | Messages that do not fit the client or server classification, such as informational or system-level entries. |

## Properties

Properties are read-only metadata shown in the **Properties** pane.

| Property | Description |
| --- | --- |
| Created | File creation date and time. |
| Modified | Date and time the file was last modified. |
| Accessed | Date and time the file was last accessed. |
| File Size | Size of the file in bytes. |
| Index Size | Number of indexed entries. |
| Average Line Size | Average number of bytes per entry. |
| Text Encoding | Character encoding (typically UTF-16 LE for MSI logs). |

## Options

Options are configurable settings found under **File > Source Settings > MSI Log**.

| Option | Values | Description |
| --- | --- | --- |
| Load / Save Full Index | Yes, No | When enabled, the entry offset index is persisted to disk for fast reopening. |
