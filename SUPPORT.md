# Getting help with Log Lion

## Look it up first

- Press **F1** in Log Lion, or read the same guide in [docs](docs/README.md).
- Search the [issues](https://github.com/RegalLogic/loglion/issues) and
  [discussions](https://github.com/RegalLogic/loglion/discussions). Someone may have
  asked already.
- The [common questions](https://www.regallogic.com/support/support.html) on our website
  cover the Security log, ETL manifests, debug output from services, and installing
  extensions.

## What to include

A report we can reproduce is a report we can fix. Please give:

1. **Your Log Lion version**, from **Help ▸ About**, and whether you installed it from the
   Microsoft Store or with the MSI installer.
2. **Your Windows version**, from **Settings ▸ System ▸ About**.
3. **What you did, what you expected, and what happened instead.**
4. **The kind of log**: its format or file extension, and roughly how big it is.
5. **A sample**, if you can share one safely (see below).
6. **Screenshots**, if the problem is something you can see.
7. **Extensions** you have installed, from **Tools ▸ Extensions**, if the problem involves one.

## Sharing logs safely

Issues and discussions here are public. Logs often contain user names, computer names,
IP addresses, URLs, tokens and other secrets.

- Share the fewest lines that show the problem.
- Replace anything sensitive with a stand-in of the same shape, such as `10.0.0.1` for an
  address or `user1` for a name, so the log still parses the same way.
- If the problem only shows up with the real file, say so in the issue and we'll arrange
  a private way to send it.

## Response times

We read every issue and discussion, and answer as soon as we can, usually within a few
business days. Organizations with a license can also email
[contact@regallogic.com](mailto:contact@regallogic.com) directly.
